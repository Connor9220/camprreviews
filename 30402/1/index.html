Multipass profile with start point and Lead In/Out on the class tray

A captioned GUI walkthrough recorded by the campr review harness. It follows one Profile from a single pass to three passes per layer, then shows how Lead In/Out behaved on top of the new Line of Sight linking.

Chapters

    Setup

    Part
    Class tray (CAM 101 Lesson 3)
    Operation
    Rough Profile, 3 passes, stepover 0.05 in
    Start point
    Front edge, X 5 in
    Lead In/Out
    Tangent in 1 in, arc out 90°
    Clearance
    8 in

    Finding

    With Linking set to Line of Sight, Lead In/Out treated each 1 mm hop between passes as a cut. It added lead-in and lead-out moves into the tray wall: 11 cuts, up to 3.2 mm deep.
