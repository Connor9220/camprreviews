CAM unit tests with the PR applied: Ran 2094 tests · OK (skipped=13, expected failures=4)

Test model

  • halfdisc-tol0.1.FCStd

TL;DR

  • Fixed: the "Wire is not closed" error from the #33644 comment is gone. On main, the author's PCB file fails Profile; with the PR, Profile and Pocket Shape both recompute.
  • Minor, new with this PR: a face that the tolerant cut collapses is now dropped without any message. With the job's Geometry Tolerance at 0.1 mm (the PCB file uses that), a 1 mm half-disc floor gets no toolpath at all. Main fails the op instead. A warning when a face is dropped would cover it.
  • Ordinary jobs don't change: pocket-island (27 ops) and class tray are identical to main. The CAM unit tests pass.

What the PR changes

One line in Path.Geom.combineHorizontalFaces(): after bboxFace.cut(faces, tol), open wires are filtered out before Part.makeFace(..., "Part::FaceMakerBullseye"). The old (pre-#31074) code had the same isClosed() filter, so this puts it back. The function is used by Profile (horizontal faces), Pocket Shape, and Adaptive.

GUI / task panels / old files Not affected: no property, panel or file-format change.

Finding: faces larger than the tolerance can disappear without a warning (minor)

The fuzzy cut doesn't only collapse faces that are below the tolerance. Two-edge faces (arc + line, lens or half-disc shapes) come out as an open wire up to roughly 10× the Geometry Tolerance. The PR drops that wire, so the whole face vanishes from the op and nothing is logged.

Half-disc floors next to a normal face, run through the function (PR):

Geometry Tolerance Largest half-disc dropped Kept from
0.01 mm (default) 0.1 mm diameter 0.2 mm
0.05 mm 0.5 mm 1.0 mm
0.1 mm 1.0 mm (0.39 mm²) 1.5 mm

Lens shapes at 0.1 mm behave the same way: 2 × 0.2 mm and 1 × 0.5 mm lenses are dropped. In every one of these cases main raises Wire is not closed instead.

End to end in a real job (halfdisc-tol0.1.FCStd): a 40×30×5 block with 1 mm deep floors (a 10×8 rectangle, a 1 mm half-disc and a 2 mm half-disc), and Profile Inside plus Pocket Shape on all three floors with a 0.2 mm tool:

  • Tolerance 0.01: all three floors get a pass.
  • Tolerance 0.1, main: both ops are Invalid (Wire is not closed).
  • Tolerance 0.1, PR: both ops are Up-to-date, but the 1 mm half-disc has no pass, and the Report view shows nothing.

With the default tolerance only sub-0.1 mm slivers are affected, which is harmless. But PCB isolation jobs like the author's use 0.1 mm, and there a skipped 1 mm region means copper that isn't milled. The PR is still better than an op that fails outright. Suggestion: log a warning (with the count or location) when open wires are dropped, or fall back to a non-fuzzy cut for those faces.

Related, also on main: if every selected face collapses (e.g. a single 1 mm half-disc at tol 0.1), the PR raises Part::FaceMaker: result shape is null where main raised Wire is not closed. Both are errors, so this is no regression, but an early "nothing to process" check would read better.

Repro

  1. Make a block with a 1 mm diameter half-disc pocket floor and any normal pocket floor.
  2. Profile (Inside, 0.2 mm tool) on both floor faces.
  3. Job > Geometry Tolerance = 0.1 mm, recompute.
  4. The half-disc gets no pass, and there is no message.

Not in the PR description

  • Faces whose outline collapses under the job's Geometry Tolerance are now silently left out of Profile and Pocket Shape instead of failing the op (tested; see the finding).
  • The same change reaches Adaptive (it calls the function with the default 0.01 tolerance) (not tested beyond the class tray A/B, which is identical).

Included from other PRs

  • #31074 (closed; its change is already on main): context only. This PR restores the isClosed() filter that #31074's rewrite dropped. Checked.
  • #33644 (open): context only. The linked comment's PCB file is the repro used above.

Issues

  • Report in the #33644 comment ("Wire is not closed" on Profile and Pocket with cam_pcb_test.FCStd): fixed. Reproduced on main (Profile), and it recomputes on the PR.
