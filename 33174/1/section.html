Defect: modal commands break absolute arc centers

Post-only probe (hand-written commands through the test fixture, no operation or Clipper involved):

== commands=True
G2X0.000Y10.000I0.000J0.000
G2X-10.000Y0.000I0.000J0.000
G2X0.000Y-10.000I0.000J0.000
== commands=False
G2X0.000Y10.000I0.000J0.000
X-10.000Y0.000I0.000J-10.000      <- incremental
X0.000Y-10.000I10.000J0.000       <- incremental
G3X10.000Y0.000I0.000J0.000

GUI, review3 FreeCAD: Helix on a Ø16 hole centered at X40 Y30, Ø6 end mill, Machine "Dynapath Modal" (dynapath post, commands duplicates off):

G1Z18.175F300.000
G2X42.400Y31.800Z15.979I40.000J30.000F503.381
X37.600Y28.200Z13.783I-2.400J-1.800F503.381     <- should be I40.000J30.000
X42.400Y31.800Z11.588I2.400J1.800F503.381

With the default Machine (commands on) every arc has I40.000J30.000.

Cause: _optimize_duplicates_doubles() clears the name of a repeated G2; convert_command_to_gcode() dispatches by name, so the nameless arc never reaches DynapathPost._convert_arc_move().
