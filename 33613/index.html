Defect: twist direction into an arc

shortcut() builds each arc's tangent as radvector.cross(Vector(0, 0, 1)):

  • incoming arc (queue[1]): radvector = center minus end point, so the result is the CCW tangent: right for G3, backwards for G2;
  • outgoing arc (queue[0]): radvector = start point minus center, so the result is the CW tangent: right for G2, backwards for G3.

segmentAngleXY() rotates the tangent 180 degrees for G2; shortcut() does not. With one tangent backwards, twistCW picks the long way around the corner.
