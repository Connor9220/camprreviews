From the code (not reproduced)

These came from /code-review medium 33739. I could not trigger them from FreeCAD.

  • Adaptive.cpp:968: SimplifyPaths replaced CleanPolygons. Clipper 1 emptied polygons that dropped below 3 points; SimplifyPath can leave a 2-point, zero-area path in the cleared area. Compute2DPolygonCentroid then divides by zero area in initToolDir. The same pattern is at lines 992 and 2406.
  • Adaptive.cpp:2446: in FindEntryPoint's symmetry-breaking retry, GetBounds on an empty Paths64 returns sentinel INT64 extremes, where Clipper 1 returned a zero rect. The rect is then built from extreme coordinates, and lastValidOffset is stale.
  • TestPathAdaptive.py:609: the new test's comment says non-model-aware Adaptive only sees cleared area at or below Z=0. That is no longer true after the depth fix. The test puts the floor at Z=-1, so it covers the arc fix but not the depth fix.
