Edge cases of the moved check (base → PR)

Run through convert_command_to_gcode() on a configured processor:

Command Setting Base PR
G0 Z5 Z left out G0 dropped
G0 F10 feed on rapids off G0 dropped
G1 at the same point duplicates suppressed G1 dropped
G4 P1 P not in the parameter order G4 dropped
G4 P1 twice duplicates suppressed kept both kept both
G81 same hole twice default kept both kept both
G82 ... P0.5 P not in the parameter order G82 X Y Z F R same
G2 full circle at the same point duplicates suppressed G2 I J same
G1 F5, G80 default kept kept

The canned-cycle extension can't drop a real hole: the machine state stores the retract height as Z after a cycle, so a cycle's depth Z always differs and is written, and R/Q are not tracked.
